# Vetus Lodge Daily Sales

Live web app for Vetus Lodge (Mumbwa, Kaoma, Kasempa): check-ins from the DS668 lock system, payments, director-approved waivers, and daily deposits.

- Front end: static `index.html` + `app.js` (no build step), hosted on Vercel.
- Back end: Supabase project "Vetus Lodge" (tables, row-level security, RPC functions, `admin-users` edge function).
- Laptop helper: `VetusSync` (PowerShell) in `C:\DS668 Locks System\VetusSync` — waiting for DS668 database access from the supplier.

Author: Kalaluka Sydney Nawa (Urunji Innovations).
